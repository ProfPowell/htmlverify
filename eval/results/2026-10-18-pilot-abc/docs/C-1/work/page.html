Checking rental availability

To check whether an item is free, send a GET request to /v1/items/{id}/availability with start and end dates.
On this page
  • Request
  • Response
  • Errors

Request

Request example:

GET /v1/items/kayak-tidewater/availability?start=2026-11-08&end=2026-11-09
Authorization: Bearer <token>
Parameters
Type Required Default
start date required
end date required
units integer optional 1

Response

Response example:

{ "available": true, "units": 3 }

Errors

404
The item doesn't exist.
422
end is before start.
