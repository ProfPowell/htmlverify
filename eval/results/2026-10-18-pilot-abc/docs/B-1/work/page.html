To check whether an item is free, send a GET request to /v1/items/{id}/availability with start and end dates.

Request

GET /v1/items/kayak-tidewater/availability?start=2026-11-08&end=2026-11-09
Authorization: Bearer <token>
Parameters
NameTypeRequiredDefault
startdaterequired
enddaterequired
unitsintegeroptional1

Response

{ "available": true, "units": 3 }

Errors

  • 404 if the item doesn't exist
  • 422 if end is before start
