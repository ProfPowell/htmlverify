# nav/primary

The site's main navigation: a horizontal list of links.

Native navigation, which works without JavaScript: a labeled nav landmark with a list of links, styled by Vanilla Breeze's horizontal nav classes. The current page carries aria-current="page".

Vanilla Breeze's nav-bar sets aria-current itself, but it's a navigation landmark only once its script runs; the plan knows the current page, so this stays native.
